# GalarShrines
 Adds a modifiable tag to spawn Galar Birds from shrines

## Give Command
### /giveorb <player> <Articuno|Zapdos|Moltres> <full|empty|value> \[galar]
 <value> should be replaced with any integer value 1-375<br />
 \[galar] is optional and adds whatever the NBT tag is defined in the config
