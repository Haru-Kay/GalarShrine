# GalarShrines
 Adds a modifiable tag to spawn Galar Birds from shrines
 Pixelmon Add On 9.1.12

# Give Command
## Non-Full Orb
### /give player pixelmon:uno/dos/tres_orb{Galarian:true,Damage:value}
 Pick either `uno_orb`/`dos_orb`/`tres_orb`.<br />
 `Galarian` can be changed in config.<br />
 `Damage` value scales 1-375, with 375 being full.
## Full Orb
### /give player pixelmon:common_stone{Galarian:true,CustomModelData:value}
 `pixelmon:common_stone` can be changed in config.<br />
 `Galarian` can be changed in config.<br />
 `CustomModelData` value can be 1, 2, 3, corresponding to Articuno, Zapdos, Moltres.
